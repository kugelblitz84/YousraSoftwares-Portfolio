# YusraSoftwares Website

Static marketing and portfolio website for YusraSoftwares, built with HTML, Tailwind CSS, and Alpine.js.

## Pages

- `index.html` — company homepage, services, process, work, about, team, insights, and contact
- `projects.html` — filterable project and case-study archive
- `case-study.html` — reusable project case-study template
- `blog.html` — Insights archive
- `blog-article.html` — reusable insight article layout

## Content placeholders

Bracketed values such as `[PROJECT NAME]`, `[COMPANY EMAIL]`, and `[TEAM MEMBER NAME]` are intentional. Replace them only with verified company information. The contact form remains disabled until a verified delivery endpoint is configured.
